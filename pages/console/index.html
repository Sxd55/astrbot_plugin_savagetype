Savage Type

人格读 AstrBot。主人记忆全局生效，人物档案点名才用。

主人记忆

主人（QQ 或 ChatUI）的指令与自述，经 AI 缩写和审核后写入；这些内容全局可注入。

学习审查

黑话、few-shot、人格草稿。批准后才注入；支持按状态/类型筛选、全选和一键批准、驳回。

待审记忆

审核不通过的条目。通过才写入；删除即丢弃。主人会收到 QQ 通知，回复「是/否 + 编号」也可以。

待确认覆盖

高证据事实被挑战时的确认队列。

说话人归并

同名不同 QQ 不会自动合并。

事件记忆

一段连续聊天整理成「一件事」：经历、决定、聊过的话题。追加式，同一话题不同时期也各存一条；待审事件确认后才参与注入。

QQ 里出现过的每个人自动建档，空档案默认 7 天后清理。

选一个人

左侧点选档案查看、修改昵称备注和条目。

注入显微镜

最近几轮主链实际注入了什么：路由、来源、去重、过滤原因、字数与窗口。

聊天导入

导入的聊天记录标记为 import / 未审核，不烧 AI 审核。

回收站

已归档的记忆可以恢复；如果槽位已被新记忆占用会阻止恢复，避免出现两条冲突事实。

原始诊断

保存后立刻生效。模型下拉按类型分开：抽取/整理/审核只列对话模型，Embedding 与 Rerank 各自只列对应类型（AstrBot 原生配置页目前不支持这两类的选择器，需要手填 ID）。

外观

着色器渐变：主色 = UI 强调色，其余两色与主色一起驱动背景的实时流动渐变场。点预设直接切换，或用取色器完全自定义。

动态颜色开启后，按「极光 → 碧金 → 暮霞 → 午夜 → 森林」顺序循环，每 1 秒停留、5 秒平滑过渡；手动点预设会关闭动态。系统开启「减少动态效果」时不播放。
